How I work

The order I learned in finance: agree on the number, then build on it.

01First

Define the KPIs

Write down what every number means before any chart exists, so everyone reads it the same way.

02Then

Clean once, reconcile

One source of truth, checked against the system it came from, until the totals match.

03Finally

Answer, then show

Lead with the decision and its cost. The dashboard holds the evidence.
